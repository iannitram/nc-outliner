C Outline list ("My outlines") and the empty state

The list moves into the left navigation, so you can switch outlines without leaving the one you're in. Opening the app goes straight to the outline you last had open. With no outlines yet, the content area shows Nextcloud's standard empty-state layout instead of a single line of text.

Why the list moves into the navigation. Today the navigation holds one "My outlines" button and a theme drop-down, and the list is a separate page you go back to. The Notes and Deck apps put the list in the navigation instead, which is what people expect in Nextcloud.

Each entry shows the outline's name and when it was last edited. The ⋯ on hover is there for later actions such as "Show in Files". It holds nothing new in this pass, so it can wait.

Theme becomes three plain choices under Outliner settings, Nextcloud's usual place for app settings. "Auto" is renamed "Follow Nextcloud" so it says what it does.

D A new, empty outline

"New outline" opens with the caret already in the first row, so you can just type. The "Add first row" button goes. A short keyboard card sits under the rows and goes away once the outline has a few rows, or when you hide it.

E Publish to Doc

Three steps. (1) Publish in the top bar opens Nextcloud's own folder picker, titled with the document's name so you know what will be written. (2) The picker covers the whole page, navigation included. (3) When it's done, a toast says where the document went and offers to open it, and the status line keeps that link afterwards.

F Versions

Versions open in Nextcloud's right-hand sidebar, the same place Files shows versions, so they never sit under the left navigation. Picking a version shows it in the main area, drawn as an outline in the same style, never as raw OPML. A banner says it's read-only and offers Restore.

G Narrow window and phone

The spec rules out a phone layout for 1.0, but "narrow screens must not break". Three rules give that for free. The page column shrinks with its padding instead of overflowing. Publish drops its label below about 760 px of content width. Indents shrink from 24 px to 16 px per level below 600 px. Nextcloud already turns the navigation into a drawer and the sidebar into a full-screen panel on small screens.

What's not designed for phones. Drag-and-drop (M9) stays a desktop pointer action, so the handle doesn't appear on touch. Moving rows still works from the keyboard with Alt+↑/↓.

On a phone, picking a version closes the panel and shows the preview with the same banner as on desktop. "Back to current" brings the list back.

H Where sort lives

Sort rearranges the whole outline for good, so it shouldn't sit one click away all the time. It moves into the ⋯ menu as "Sort rows…" and opens a small dialog that says what it will do. Undo (Ctrl+Z) reverses it, as it does today.

The ⋯ menu holds the actions you use less often: Sort rows…, Versions (also on the clock button, but kept here for narrow widths), and Report a bug once M14 lands. The current sort options were "Topic / Status / Note" with an Ascending button and a separate "Sort rows" button. They become plain choices, with "Topic" renamed "Row text" and "Status" renamed "Checkbox (from imported files)", because 1.0 doesn't show checkboxes. Sorting only the selected rows (#31) can join the dialog when row selection exists.
