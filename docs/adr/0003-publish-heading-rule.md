# 0003: Publish to Doc heading rule

Date: 2026-10-25. Decided in the spec interview.

**Decision.** Top-level rows become Heading 1. A second-level row that has children becomes Heading 2. Every deeper row, and a second-level row with no children, becomes a nested bullet. A row's note becomes a paragraph under it.

**Check.** A sample `.odt` published from a sample outline, which I open and approve before Publish to Doc counts as done.
